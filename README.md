# Could You Be Any More Compliant? – Audit Tool

A lightweight, client-side compliance audit tool designed to evaluate privacy, consent, and tracking practices across websites — including Shopify environments and CMP implementations like Osano.

## 🚀 Features

- Privacy & transparency checks (Privacy Policy, tracking disclosure)
- Consent validation (banner presence, prior blocking)
- User rights compliance (DSAR, Do Not Sell/Share)
- CIPA risk detection (session replay tools)
- Shopify-specific audit logic
- CMP validation (Osano detection)
- Automatic scoring + grading system (A–D)
- Export results as a downloadable PDF
